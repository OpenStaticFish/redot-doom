# Original access-card artwork

The blue/red horizontal access cards are original to DEAD SIGNAL and are
generated by `tools/build_pickup_sprites.py`. Each has a clipped metallic
outline, colored access stripe, magnetic strip, gold contact chip, security
number, barcode and blinking reader indicator.

The builder derives both the world animation atlas and the aspect-preserving
HUD icon from the same source artwork. These images are not Freedoom key/token
sprites and do not need downloading to rebuild.
