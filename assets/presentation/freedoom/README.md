# Presentation source art

Enemy rotations, scenery, effects, wall/floor/door textures and marine portraits
are from **Freedoom 0.13.0**, Copyright © 2001–2024 Contributors to the Freedoom
project, distributed under **BSD-3-Clause**. The complete license is in
`COPYING.txt`; upstream contributors are listed in `CREDITS`.

Source: https://github.com/freedoom/freedoom/tree/v0.13.0

`tools/build_world_art.py` retains source PNGs, colors and transparency, and
composes aligned atlases with eight-way enemy rotations. Combined mirrored
rotations and authored horizontal sprite pivots are preserved. Runtime sizes,
hitboxes and gameplay are defined separately in the game's scripts.

Key-access stripes on doors are an adaptation for DEAD SIGNAL. Animated acid
and lava use the included flat frames. The beveled title, metal UI panels and
exit-switch graphics are original and generated by `tools/build_ui_art.py`.

Rebuilding is offline; `--fetch` is only needed to retrieve missing source files
from the pinned upstream release with `gh`.
